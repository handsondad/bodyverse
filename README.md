# 认识身体

这是一个面向儿童的身体认知学习网站原型，当前版本的核心目标是把“认识身体的奥秘”这件事讲清楚、讲一致、讲出年龄梯度。

当前版本已进入主题化迭代阶段：
- 主题主轴固定为“认识身体的奥秘”。
- 范围固定为五个部位、四条主线、四个年龄层。
- 当前阶段收尾后，按主题进入下一轮有边界迭代。

## 身体奇遇记：小念问，爸爸答

首页只有三样：标题、小念和爸爸的 3D 动画、9 个身体部位（大脑与神经、眼耳鼻舌与平衡、心脏与血液、鼻子与肺、嘴巴肚子与便便、皮肤汗和伤口、骨头与肌肉、生病与免疫、长大与生命）。点进一个部位是从入门到挑战排好的问题列表，点开一个问题就是完整的一问一答：

- 小念先说身体的现象，爸爸回答；小念接着爸爸刚说的话追问，爸爸再往深里讲，5 到 8 轮问答一路讲到原理，最后小念用自己的话总结。从头读到尾，就能弄懂标题里的问题。
- 有些回答配了图解步骤，和心脏、呼吸相关的回答能直接跳进 3D 放大旅程的对应一层。
- “我是从哪里来的”“人为什么会变老”需要大人确认后打开；每个问题底部有折叠的“给大人”提示。
- 内容在 `src/data/questions/`，一个身体部位一个文件。写新问题时可以先跑 `node tests/dialogue-rules.mjs src/data/questions/<文件>.ts`，它会检查每句追问是不是接着爸爸上一句的话、回答长度、术语和 3D 场景链接。

### 讲解动画

每个问题旁边有一部讲解短片，一场戏配一轮问答：播到哪一轮，左边那一轮问答就亮起来；点回答下面的「🎬 看动画」直接跳到那一段。

- 画面底图是解剖图集：`tools/atlas/` 把 BodyVista 的人体模型按 8 个视角（全身、头部正面、头部侧面、胸腔、肚子、手、胳膊、腿）渲染成对齐的图层，比如胸腔视角里的骨头、肺、心脏、膈肌可以随意叠放、单独亮起来、让心脏跳肺鼓。图集还量好了 80 多个器官锚点，动画里直接写 `"heart"`、`"nose"` 就能把标签、箭头贴上去。来源和许可限制见 `public/anatomy/CREDITS.md`。
- 动画的做法参考了 HyperFrames：画面是时间 t 的纯函数，可以暂停、拖进度条；一张图逐步长出来，爸爸说到哪个部件，哪个部件才出现。动画元素有标签、光圈、波纹、流动的小点、箭头、表情图标、示意图形、大字、计数、进度条和「常见误会」卡。
- 有配音：小念（`zh-CN-YunxiaNeural`）和爸爸（`zh-CN-YunxiNeural`）把整段问答读出来，正在说话的气泡会亮起来，宽屏上对话会跟着滚动；动画按配音长度自动放慢，心跳、呼吸这些循环动作保持原速。播放器右下角的 🔊 可以关掉声音，回到 1 分钟左右的无声版。音频在 `public/voice/`，改了问答文字以后跑 `npm run voice` 重新配音（需要 `python -m pip install edge-tts`、ffmpeg，并联网）。
- 动画数据在 `src/data/films/`，一个身体部位一个文件，格式见 `src/data/films/types.ts`。写完先跑 `node tests/film-rules.mjs src/data/films/<文件>.ts`，它会检查场次和问答是否对应、时长、锚点和图层是否存在、文字长度，以及标签和字幕在镜头推近以后是否还在画面里、同一时刻的元素会不会太挤。查锚点坐标用 `node tools/atlas/anchors.mjs <视角>`。

## 心脏探索样板

首页点击“心脏探索样板”，或在人体图选择心脏，进入“为什么跑步后心跳更快”的探索。

- 五个尺度各有示意图、四年龄层讲解、追问和比喻边界。年龄决定讲解方式和建议深度，不锁住孩子的好奇心。
- “心脏”尺度提供可旋转的 3D 卡通心脏，跳动快慢跟随模型心率，可切换回平面图；设备不支持 3D 时自动使用平面图。3D 部分按需加载，详见 [3D 动画与 Blender 接入研究](docs/18-3D动画与Blender接入研究.md)。
- 心脏探索开头是“和小念一起跑一跑”互动实验（也可以换成爸爸）：先猜心跳会怎样，按住按钮让动画角色在小星球上奔跑，实时看心率和呼吸曲线上升、停下后慢慢恢复；拖动透视镜看身体里跳动的心脏、鼓起的肺和流动的血液，还能开心跳声、跟着节奏拍。角色为 CC0 动画模型，来源见 `public/models/CREDITS.md`。
- 先选择猜想，再调节教学模型心率，观察固定每搏量下的一分钟送血量；可播放、暂停心跳示意，并遵循系统减少动态效果设置。
- 孩子可编辑三格画面描述、旁白、镜头尺度和下一个问题，预览作品，保存本机草稿或导出 JSON 分镜。
- 草稿不会上传或公开；切换讲解年龄不改写作品。离开心脏主题或刷新前请保存，清除浏览器数据会移除本机草稿。
- 当前没有外部媒体嵌入、作品发布或视频生成。分镜导出用于后续制作，不是视频文件。

实现边界、内容审核要求和后续媒体接入见 [心脏探索样板设计](docs/17-心脏探索样板设计.md)。这是独立的探索与创作试点，不扩大其余四个部位的功能范围。

## 使用方式

1. 在仓库根目录安装依赖并启动（npm install && npm run dev）。
2. 按 docs/07 做主题一致性评审。
3. 每周固定一次，按 docs/12 做主线抽查并记录结果。
4. 在页面内“抽查执行工作台”录入记录与闭环项。
5. 操作细节参见 docs/15（含周次规则、快捷操作、回收站规则）。
6. 周报输出前先看预览，再按场景选择领导版或教研版。
7. 周报口径与环比说明参见 docs/16。
8. 将每周结果回填 docs/13，持续追踪待修项闭环状态。
9. 每月最后一周，按 docs/14 做月度回顾并提炼下月行动项。
10. 如需修改，按 docs/08 的模板提交单点微调需求。

已验证命令：
- npm run typecheck
- npm run build

探索样板测试：`npm test`（使用 Node.js 原生 TypeScript 类型擦除，需要 Node.js 22.18+，或支持该能力的更新版本）。

## 前端工程说明

当前仓库根目录即 Vite + React + TypeScript 工程。

### 主要结构

- src/main.tsx：React 入口
- src/App.tsx：页面装配与业务编排
- src/components/*.tsx：功能面板组件（Header/Story/Science/Illness/ProgressQuiz）
- src/hooks/*.ts：状态与交互 hooks（持久化、播放流程、语音、答题、科学实验、学习概览）
- src/lib/content-adapter.ts：内容数据到 TS 类型的适配层
- src/types/content.ts：核心类型定义
- src/data/*.ts：当前内容数据源
- .gitignore：忽略构建产物与依赖目录

### 常用命令

- npm run dev
- npm run typecheck
- npm run build
- npm run preview
