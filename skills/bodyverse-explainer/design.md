# 页面风格

整体感觉：暖色、圆润、像一本给孩子的绘本。米白偏橙的底，白色卡片，粗一点的浅色描边，大圆角，轻轻的弹跳动效。字体是 `'Comic Neue', 'Ma Shan Zheng', cursive`（马善政手写体），在 `src/index.css` 里统一设置，新组件不用另设字体。

## 用现成的变量

都在 `src/index.css` 的 `:root` 里，新样式优先用它们，不要写死相近的颜色：

| 用途 | 变量 |
|---|---|
| 背景 | `--bg-primary #fff8f0`、`--bg-secondary`、`--bg-card #fff` |
| 文字 | `--text-primary #5d4e37`（深棕，不用纯黑）、`--text-secondary #8b7a5c`、`--text-muted` |
| 描边 | `--border-color #ffe0cc`、`--border-light` |
| 强调 | `--accent-orange #ff9f43`（主色）、`--accent-blue`、`--accent-green`、`--accent-red`、`--accent-purple` |
| 阴影 | `--shadow-sm` / `md` / `lg`：都是淡淡的暖红色阴影 |
| 圆角 | `--radius-sm 16px`、`--radius-md 24px`、`--radius-lg 32px`；按钮、标签用 `999px` 胶囊 |
| 动效 | `--transition-fast` / `normal`：带一点回弹的 cubic-bezier |

每个身体系统有自己的颜色（`src/data/questions/types.ts` 的 `color`），页面里通过 `--bubble` 变量混色：`color-mix(in srgb, var(--bubble) 16%, white)` 做浅底，45% 做描边。

## 页面的样子

- **首页**：
  - 渐变大标题"🚀 身体奇遇记"，副标题"小念和爸爸探索身体的奥秘"；
  - 下面是小念和爸爸的 3D 场景，配两个对话气泡；
  - 再下面是"身体部位"，9 张系统卡片排成 3 列，平板 2 列，手机 1 列。卡片左边是大 emoji，右边是标题、孩子口吻的一句钩子、题目数量。
- **问题列表**：
  - 顶部一块虚线框的介绍；
  - 问题按入门 / 进阶 / 挑战分组，每组 2 列卡片；
  - 卡片上是问题标题、触发场景，加学科和"⭐ 看过"徽章。
- **问答页**：
  - 宽屏时左边是对话，右边是固定在视口里的讲解动画（`1fr : 1.1fr`）；宽度 ≤900px 时，动画在上、对话在下。
  - 小念的气泡靠右，暖黄底 `#fff7e6`、橙描边、字加粗；爸爸的气泡靠左，白底、浅蓝描边 `#cfe0f7`。
  - 头像是圆形，小念橙边，爸爸蓝边。
  - 正在讲的那一轮整块淡橙底加描边；正在说话的气泡外圈是橙色。
  - 页尾依次是"小念还想问"（同系统的下几题）和折叠的"👨‍👩‍👧 给大人"。

## 组件的做法

- **按钮**：
  - 普通按钮是胶囊形、白底，加 2px `--border-color` 描边，悬停时上移 1–3px；
  - 当前项用 `#ffe4d0` 底加 `#ff9f43` 描边，并加 `aria-current`；
  - 主按钮是橙色实心圆，下面加一道深橙阴影 `0 3px 0 #e07f22`，按下时下沉。
- **卡片**：白底，`--radius-md` 圆角，2–3px 浅色描边，`--shadow-sm` 阴影；悬停时上移，阴影加深。
- **出场动画**：气泡、步骤格用 `qa-pop`（向上 8px、缩放 0.97 → 1），按顺序错开 70ms。动画都要尊重 `prefers-reduced-motion`：在这个媒体查询里关掉动画，换成静态描边。
- **图解步骤**：`qa-steps`，浅蓝格子横排，每格一个大 emoji 加一行小字，格子之间用"→"。
- **可访问性**：
  - 图标按钮要有 `aria-label`；
  - 区块用 `aria-label` 或 `aria-labelledby`；
  - 焦点框是 3px 蓝色 `#225dac`；
  - 不要只靠颜色表达状态。

## 动画舞台

- 4:3 圆角舞台。解剖视角是淡蓝色径向渐变底，空白画布是奶油色渐变底。
- 舞台上的字用 `.film-text`：粗体，白色描边（`paint-order: stroke`），放在任何底图上都清楚。
- 左上角是场次标题胶囊（橙色圆号码加标题）。误会卡浮在舞台底部中间，错的那句会被一道红线划掉。
- 舞台下面依次是：播放按钮、进度条、时间、声音开关，再下面是一排分段胶囊，点一下就跳到那一场。
