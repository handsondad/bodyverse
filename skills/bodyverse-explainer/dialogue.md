# 写问答

问题写在 `src/data/questions/<系统>.ts`，类型见同目录 `types.ts`。写完跑：

```
node tests/dialogue-rules.mjs src/data/questions/<系统>.ts
```

## 字段

| 字段 | 写什么 |
|---|---|
| `id` | 英文短横线，如 `sneeze`、`foot-asleep`；也是动画和配音的文件名 |
| `system` | 9 个系统之一，和文件一致 |
| `difficulty` | 1 入门、2 进阶、3 挑战。列表按它排序 |
| `sciences` | `生物` / `物理` / `化学` 等学科标签 |
| `title` | 小念口吻的问题，必须带"？"。可以再加一句感叹："想忍都忍不住！" |
| `trigger` | 小念刚遇到的那件事，一句话，具体到场景："鼻子一痒，还没反应过来就'阿嚏'了一声" |
| `dialogue` | 5–8 轮 `{ nian, dad, show? }` |
| `parentTip` | 给大人：补充背景、什么情况要看医生 |
| `parentGate` | 可选。生殖、出生、死亡这类话题写一句给大人的说明，页面会先要大人确认 |

## 检查器会拦的

- 5–8 轮；每轮小念和爸爸都要有话。
- 除最后一轮外，小念每句都是问句，带"？"。
- 最后一轮小念要以"我懂了"或"我明白了"开头，用自己的话总结。
- 从第 2 轮起，小念的问题必须用上爸爸上一句里的一个词，追问要接得上。
- 爸爸每句 20–170 字。
- 不用术语表里的词：ATP、受体、神经元、轴突、pH、潮气量……这些都要换成孩子听得懂的说法。
- `show` 里的 `steps` 至少 2 格，`journey` 的站点要存在。

## 写好的标准（检查器管不到的）

**小念**：
- 7 岁男孩的口气，短句，带情绪："阿嚏！""真的在滑！"
- 追问要"顺着往下挖"，不要跳题。好的追问来自爸爸刚说的那个新词：爸爸说了"脑干"，小念就问"脑干怎么知道要打喷嚏？"。

**爸爸**：
- 先回答问题本身，第一句就给答案，再解释。
- 一个比方只讲一件事，用孩子见过的东西：传送带、汽水瓶、门的合页、粘虫板、小火车。
- 比方说完说真名，只说一次："……叫神经。"后面就可以直接用。
- 数字要真实，最好有来源可查。屏幕和动画里出现的数字只能是爸爸说过的。
- 不确定就直说："科学家还不完全确定，可能是……"
- 有流传的谣言，就点名辟谣："有人说……，那是谣言。"
- 安全提醒放在对话里讲成习惯（"别硬捏住鼻子"），具体的就医信号放 `parentTip`。

**追问链的常见顺序**（不必每次都全用）：
1. 现象是怎么回事（是什么）
2. 谁在管、发生在身体哪里
3. 一步步怎么发生
4. 为什么非得这样，不这样会怎样
5. 常见误会或特殊情况
6. 我能做什么
7. 小念总结，爸爸给一个好习惯

**`show`**：
- 爸爸讲"一步一步"时，配 `steps`：2–4 格，每格一个 emoji 加 ≤8 字。
- 和心脏、呼吸相关的，可以配 `journey` 跳进 3D 放大旅程。

## 例子（节选自 `breathe.ts` 的 `sneeze`）

```ts
{
  id: "sneeze", system: "breathe", difficulty: 1, sciences: ["生物", "物理"],
  title: "为什么我会突然打喷嚏？想忍都忍不住！",
  trigger: "鼻子一痒，还没反应过来就“阿嚏”了一声",
  dialogue: [
    {
      nian: "阿嚏！爸爸，我又没想打喷嚏，它怎么自己就跑出来了？",
      dad: "因为鼻子里钻进了灰尘、花粉，或者你吸了一口冷空气。鼻子里面铺着很多很灵的“报警线”，叫神经。脏东西一碰到它，鼻子就痒，警报马上传到大脑。身体就用一个喷嚏，把这些东西“轰”出去。"
    },
    {
      nian: "警报传到大脑，可我又没想打，是谁替我决定的？",
      dad: "是大脑最下面、连着脖子的那一截，叫脑干。它管着好多不用你想的事，比如呼吸、咽口水。鼻子的警报一到，它不问你，直接按下“喷嚏按钮”。这种不用想、自动发生的动作，叫反射，所以你来不及反应。"
    },
    // ……怎么发生 → 为什么要先憋气 → 为什么闭眼（辟谣）→ 能不能忍住（安全）……
    {
      nian: "我懂了！鼻子里的神经发现脏东西，警报传给脑干，脑干自动指挥全身肌肉先憋气、再猛地放开，把脏东西轰出去。这是反射，所以我想忍也忍不住！",
      dad: "说得真好！还有个好习惯：打喷嚏时用胳膊肘内侧挡住，别用手捂，这样病菌不会沾到手上，再摸到别人。"
    }
  ],
  parentTip: "过敏、感冒、冷空气、胡椒都会引起喷嚏。频繁打喷嚏伴鼻痒、眼痒，可能是过敏性鼻炎；伴喘息或呼吸困难要就医。"
}
```

注意第 2 轮小念的"警报传到大脑"直接接的是爸爸上一句的原话，这就是追问链。
