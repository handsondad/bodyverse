# 心脏探索样板：从一个问题到一个作品

## 产品闭环

以“为什么跑步后心跳更快”为入口，而不是要求孩子先理解学科目录：

1. 提问：从熟悉的身体体验出发。
2. 追因：在全身、器官、组织、细胞、分子五个尺度切换，建立系统协作与微观机制的联系。
3. 观察：先预测，再改变教学模型中的一个变量。
4. 创作：自己设计三格讲解分镜，预览、保存，留下下一个问题。

这是现有五部位、四主线、四年龄层基础上的单主题试点。其余部位及原主线保持原样；不扩展审核工作台，也不引入后端、账号或图数据库。

## 内容与交互

每层都有关系示意图、年龄分层讲解、追问和“比喻在哪里不成立”。示意图不是医学图谱，不按真实形状或比例绘制。五层完整开放；4–6 岁建议先到器官，7–9 岁到组织，10–12 岁到细胞，13+ 到分子，不以年龄硬锁知识。

教学模型固定每次送出 50 毫升，心率可在 60–140 次/分钟之间调节，输出为心率乘以每次送血量。高年龄层展示公式。该范围仅是模型操作范围，不是儿童正常心率范围；真实运动还改变每搏量和血流分配，不能据此推导“跳得越快越健康”。动画默认静止、可播放或暂停；系统偏好减少动态效果时不播放缩放动画。

不要求孩子运动、憋气或按压身体，不采集体征，不做诊断。界面保留家长陪伴与不适求助提醒。教学文案和图示在面向真实儿童正式发布前，仍需儿童教育与生理学专业审核。

## 创作与持久化

三格初始提示分别是全身、器官和细胞；孩子可改镜头尺度、画面描述和旁白。低龄儿童可口述、大人代写。旁白填满只表示进入创作环节，不代表科学正确或通过评审。

- 本地存储键：`body-mystery-heart-storyboard-v1`，显式点击保存后持久化。
- 单设备单草稿；刷新自动恢复已保存内容，切换讲解年龄不改写作品年龄。
- 作品名称最多 80 字符，画面每格 300 字符，旁白每格 500 字符，后续问题 300 字符。
- 不覆盖读取失败的存档，除非用户主动保存新稿；读取、写入、导出失败会明确提示。
- JSON 导出包含版本、主题、年龄、标题、三格分镜、后续问题、时间及 `local-draft` 标记。导出不等于保存本地草稿。
- 不收集姓名、联系方式和健康检查数据，不上传、不自动发布。浏览器清理、换设备会丢失本地存档，建议导出备份。当前没有导入功能。

## 媒体边界与演进

当前关系图和心跳动画由本项目绘制，没有外部媒体、生成视频或自动科学评审。

外部资源不能只贴链接或直接嵌入。后续收录必须记录来源 URL、作者、许可及允许的使用方式、适用年龄、对应尺度、字幕语言、科学审核状态和比喻风险。未经审核或许可不明的资源不进入儿童展示端；公开视频可观看不等于可以下载、剪辑或再发布。

未来制作视频时，复用每格的 `nodeId`、`visual` 和 `narration` 作为分镜输入，另加时长、资产引用及制作状态。生成结果仍需检查解剖准确性、尺度、因果与旁白一致性，以及儿童适宜性。不得自动把孩子草稿发送给第三方服务或公开发布。

## 验证范围

- `npm test`：内容年龄覆盖、建议尺度有效性、固定每搏量模型边界、草稿独立性、序列化往返、异常存档拒绝。
- `npm run typecheck`、`npm run build`：类型与生产打包。
- 浏览器检查：问题入口、五尺度切换、年龄切换、模型预测与滑杆、播放暂停、作品预览、保存刷新恢复、导出、存储异常提示及窄屏布局。
