# 验收标准与发布门槛（MVP）

## 一、功能验收

1. 四条主线均可从入口走到总结页。
2. 年龄层切换后，文本与题目正确变化。
3. 每条主线至少有 1 个互动动画节点。
4. 每条主线至少有 1 次知识检查。

## 二、内容验收

1. 首批 8-12 个核心节点内容完整。
2. 四年龄层文案可读、难度有梯度。
3. 疾病类内容有清晰边界提示（教育用途）。

## 三、音视频验收

1. 语音可播放、暂停、续播。
2. 字幕与语音同步，无明显错位。
3. 动画 cue 在关键讲解点准确触发。

## 四、性能与兼容性验收

1. 移动端核心流程操作流畅。
2. 首屏加载时间可控，资源有懒加载策略。
3. 桌面主流浏览器可正常运行。

## 五、发布门槛

1. 四条主线全通过内部走查。
2. 小规模试点测试问题已闭环。
3. 上线与回滚流程已演练。
4. 指标埋点可用并可在看板查看。

## 六、上线后首周观察指标

1. 学习完成率
2. 平均学习时长
3. 语音播放完成率
4. 关键知识点答题正确率
5. 主线中途退出率
