# 15 抽查执行工作台使用说明

更新时间：2026-04-23

## 1. 目标

抽查执行工作台用于在页面内完成每周抽查记录、问题闭环、周报导出与趋势复盘，减少线下表格和手工汇总。

## 2. 功能总览

- 记录抽查：录入周次、部位、年龄层、主线、标签、问题描述。
- FIX 自动编号：选择“记录并闭环问题（自动 FIX）”后自动生成编号。
- 多维筛选：周次（单周/区间）、主线、年龄层、标签。
- 快捷周次：本周、上一周、下一周、近 4 周、近 8 周。
- 数据导出：CSV、JSON、周报 TXT。
- 周报复制：按模板一键复制（领导版/教研版）。
- 周报预览：字段对照、只看变化字段、环比上周摘要。
- 趋势复盘：主线风险趋势、标签风险趋势、周汇总表。
- 明细维护：编辑问题、状态切换、软删除、回收站恢复/清空。

## 3. 周次规则

### 3.1 合法格式

- 单周：`YYYY-Wxx`，例如 `2026-W17`
- 区间：`YYYY-Wxx~YYYY-Wxx`，例如 `2026-W15~2026-W18`

### 3.2 录入校验

- 录入新增记录时会校验周次。
- 周次不合法会阻止提交并提示修正。

### 3.3 筛选说明

- 周次筛选支持单周和区间。
- 区间起止写反时系统会自动纠正顺序。

## 4. 标准操作流程

### 4.1 每周抽查录入

1. 点击“录入周次用本周”或手动设置抽查周次。
2. 依次选择部位、年龄层、主线、问题标签。
3. 无问题时点击“记录通过”。
4. 有问题且需要闭环时，填写问题描述并点击“记录并闭环问题（自动 FIX）”。

### 4.2 每周复盘

1. 使用“筛选本周”或输入周区间。
2. 查看统计卡（总记录、FIX 数、闭环率、覆盖周数）。
3. 查看趋势图（主线/标签）。
4. 在明细表处理待处理项（编辑问题、切换状态）。

### 4.3 周报产出

1. 选择周报模板（领导版/教研版）。
2. 点击“预览周报”检查字段和环比摘要。
3. 需要发群时用“一键复制周报”。
4. 需要归档时用“导出周报 TXT”。

## 5. 字段说明

- 周次：抽查归属周，ISO 周格式。
- 部位：头部/心脏/肺部/胃部/手部。
- 年龄层：4-6、7-9、10-12、13+。
- 主线：分层解剖、场景故事、科学原理、生病就医。
- 标签：口径冲突、年龄跳级、流程断裂、证据不足。
- FIX：问题闭环编号，格式为 `FIX-YYYY-Wxx-xx`。
- 状态：已闭环/待处理。

## 6. 回收站规则

- 删除记录默认进入回收站（软删除）。
- 回收站可恢复或永久删除。
- 清空回收站后不可恢复。

## 7. 数据持久化

- 记录与模板选择均保存在浏览器本地存储（localStorage）。
- 清理浏览器站点数据会导致本地记录丢失，建议定期导出 CSV/JSON/TXT 归档。

## 8. 常见问题

### Q1: 为什么周报没有上周环比？

上周在当前筛选口径（主线/年龄层/标签）下无数据时，环比会显示“暂无同口径对比数据”。

### Q2: 为什么无法新增记录？

优先检查录入周次是否为 `YYYY-Wxx`。

### Q3: 为什么 FIX 没有生成？

只有点击“记录并闭环问题（自动 FIX）”才会生成 FIX 编号。
