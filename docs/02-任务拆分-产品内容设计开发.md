# 任务拆分（产品 / 内容 / 设计 / 开发）

## 产品（PM）

1. 输出 PRD v1（范围、目标用户、核心路径、非目标）。
2. 定义并维护验收标准（功能 + 学习效果）。
3. 维护里程碑与风险台账。
4. 每周组织跨角色评审并冻结变更。
5. 上线前完成发布清单与回滚策略。

## 内容（医学/教研）

1. 建立统一知识图谱（节点与关系）。
2. 为每个节点产出四年龄层文本。
3. 产出讲解脚本、问题卡、总结卡。
4. 统一术语与科学表述口径。
5. 疾病类节点补齐“何时就医”提示。

## 设计（UX/UI/动效）

1. 输出视觉系统（颜色、字体、组件）。
2. 完成四类模板（入口、学习、互动、总结）。
3. 制定动画模板（进入、聚焦、剖面、回顾）。
4. 完成移动端优先规范（触控、字号、间距）。
5. 完成语音播放态与字幕态设计。

## 开发（前端/音视频）

1. 搭建工程架构（路由、状态、数据层）。
2. 实现四主线容器与统一学习流程。
3. 实现局部 3D 组件并提供 2D 降级。
4. 实现 TTS 音频播放、字幕和动画 cue 同步。
5. 接入埋点（学习开始、节点完成、答题结果、播放完成率）。
6. 完成跨端适配与性能优化。

## 周节奏建议

1. 周一：计划会（锁定本周目标）。
2. 周三：中期评审（看可运行版本）。
3. 周五：验收会（按验收标准逐项过）。
4. 每天：15 分钟站会（阻塞与当日交付）。
