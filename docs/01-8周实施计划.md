# 8周实施计划（可直接开工）

## 总体目标

在 8 周内完成可上线 MVP：四条主线各 1 个完整学习闭环样本，支持年龄分层与语音动画讲解。

## 第1周：边界定义与项目启动

- 目标：冻结 MVP 范围与验收标准
- 产品：PRD v1、核心指标、用户路径图
- 内容：首批知识节点清单（8-12）
- 设计：信息架构、核心页面线框
- 开发：工程骨架、路由、主题变量
- 验收：项目可运行 + 文档冻结 v1

## 第2周：内容模型与年龄分层

- 目标：统一数据结构并可动态切换年龄层
- 产品：确认数据字段与内容流
- 内容：四年龄层文案模板与术语规范
- 设计：高保真页面（首页/学习页/总结页）
- 开发：内容 Schema 与 mock 数据渲染
- 验收：同一节点可按年龄层显示不同内容

## 第3周：主线A（分层解剖）

- 目标：打通人体总览到手部细化闭环
- 内容：人体 -> 手部 -> 骨骼/神经 -> 动作机制
- 设计：剖面与聚焦动画分镜
- 开发：主线 A 页面与基础测验
- 验收：A 线完整可演示

## 第4周：主线B（场景故事）

- 目标：打通食物旅程闭环
- 内容：口腔到排出 + 3 个深入机制节点
- 设计：流程地图与场景转场
- 开发：时间轴与流程节点交互
- 验收：B 线完整可演示

## 第5周：主线C+D（科学原理 + 生病就医）

- 目标：四条主线全部可跑通
- 内容：杠杆/压力；感冒机制与就医流程
- 设计：C/D 动效模板与问答样式
- 开发：C/D 线页面、主线切换、测验组件
- 验收：四主线端到端跑通

## 第6周：语音与动画同步

- 目标：实现讲解模式
- 内容：脚本定稿与字幕稿
- 设计：字幕、朗读高亮、播放控制样式
- 开发：TTS 接入、音轨管理、cue 同步
- 验收：语音+字幕+动画同步可用

## 第7周：测试与优化

- 目标：稳定性与易用性提升
- 产品：问题分级与修复优先级
- 内容：文案可懂度优化
- 设计：移动端触控与视觉可读性优化
- 开发：性能优化、异常兜底、埋点
- 验收：核心路径稳定，性能达标

## 第8周：发布与复盘

- 目标：MVP 发布
- 产品：发布清单、监控看板、复盘模板
- 内容：医学表述终审与边界提示
- 设计：上线素材、引导页
- 开发：发布、监控、回滚预案
- 验收：上线成功 + 指标可追踪
