# 08 内容稳定期基线与微调规则

## 目标
本规则用于在“主题回归通过”后锁定内容基线，确保后续只做小步、可追踪、可回滚的微调，不再发生功能扩展快于内容主轴的偏航。

基线来源：`docs/07-主题回归内容清单.md`（评审通过版，2026-04-20）。

## 冻结范围（当前版本）
1. 主题主轴：始终围绕“认识身体的奥秘”。
2. 结构框架：五部位 x 四主线 x 四年龄层。
3. 一句话奥秘矩阵：保持“XX的奥秘是：...”统一句式。
4. 年龄梯度：4-6、7-9、10-12、13+ 的难度与语气分层保持一致。
5. 误区纠正与总结回顾：与主线结论口径一致，不互相冲突。

涉及文件（冻结对象）：
- `src/data/mystery.ts`
- `src/data/cue.ts`
- `src/data/age-lens.ts`
- `src/App.tsx`
- `src/lib/content-adapter.ts`
- `docs/07-主题回归内容清单.md`

## 允许变更（可直接进入微调）
1. 错别字、标点、语序优化。
2. 同年龄层内的词汇降噪与可读性提升（不改变结论含义）。
3. 个别句子改写以增强孩子可复述性（不改主线奥秘）。
4. 单条误区表达过硬时的语气柔化（不改变纠正方向）。
5. 文档中评审描述补充（不新增验收维度）。

## 禁止变更（需单独立项，不在稳定期执行）
1. 新增主线、部位或年龄分组。
2. 新增页面流程、功能模块、交互机制。
3. 引入新技术栈或外部依赖。
4. 改动导致“一句话奥秘”句式不统一。
5. 改动导致同年龄层难度明显跳级。

## 微调执行流程
1. 接收点名需求：明确部位、主线、年龄层和目标句子。
2. 最小改动：只改必要行，不做顺手重写。
3. 局部核对：检查“一句话奥秘、机制链路、误区纠正、总结回顾”是否仍一致。
4. 记录变更：在本文件“微调记录”追加条目。
5. 快速回归：抽查至少 1 个同部位邻近年龄层，确认未引入梯度错位。

## 稳定期回归检查清单
- [ ] 改动后仍可用一句话讲清该部位该主线的“奥秘”。
- [ ] 4-6 文案可直接口语讲述，不依赖术语。
- [ ] 13+ 文案保留系统推理，不退化成口号。
- [ ] 同一部位四主线没有跳题或自相矛盾。
- [ ] 一句话奥秘、误区纠正、总结结论三处口径一致。
- [ ] 改动仅限请求范围，无无关扩写。
