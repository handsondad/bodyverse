# 10 下一主题：内容校准与教学闭环

## 主题目标
在不新增功能壳和页面流程的前提下，完成一轮“内容质量优先”的主题迭代：

1. 同年龄层表述风格一致
2. 一句话奥秘可复述
3. 课堂/家庭讲解可直接执行
4. 误区纠正与主线结论保持一致

## 范围边界

本主题允许：
- 文案改写与降噪
- 年龄层语气统一
- 讲义模板内容优化
- cue 节奏文案精修

本主题禁止：
- 新增主线、部位、年龄分层
- 新增页面流程或交互壳
- 引入新依赖和新技术栈

## 本轮执行顺序

1. 年龄层语言校准：
- 4-6：口语化、可直接说给孩子听
- 7-9：问题驱动，少术语
- 10-12：机制解释+因果
- 13+：系统推理+证据意识

2. 主线句式校准：
- 四主线都要回到同一“身体奥秘”
- 句式统一，避免跳题

3. 讲义模板校准：
- 课堂版：提问点更清晰
- 家长版：家庭复盘步骤更可执行

4. 回归检查：
- 一句话奥秘、误区纠正、正式结论三处一致
- 不同年龄层无明显跳级

## 交付物

- 校准后的内容数据（src/data/*.ts）
- 校准后的讲义文案（src/App.tsx 生成段）
- 一次回归记录（追加到 docs/08 微调记录）

## 验收标准

- 任意选择一个部位+主线，4 个年龄层都能连贯讲解
- 课堂版和家长版讲义都可直接用于 5-10 分钟讲述
- 构建与类型检查通过（npm run typecheck && npm run build）
