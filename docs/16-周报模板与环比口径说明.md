# 16 周报模板与环比口径说明

更新时间：2026-04-23

## 1. 目的

统一领导版与教研版周报的输出口径，确保周报复制、TXT 导出、预览展示三者一致。

## 2. 模板定义

### 2.1 领导版（摘要）

适用对象：负责人、管理层、需要快速把握风险走势的读者。

包含内容：

- 总记录
- FIX 总量
- 闭环率
- 覆盖主线
- 高频风险标签
- 关键闭环（最多 3 条）
- 环比上周摘要

### 2.2 教研版（明细）

适用对象：教研、执行、需要逐条处理问题的读者。

包含内容：

- 记录数
- FIX 数
- 闭环率
- 覆盖主线
- 问题清单（全部 FIX 明细）
- 环比上周摘要

## 3. 环比口径

### 3.1 指标

- FIX 环比：本周 FIX 数 - 上周 FIX 数
- 闭环率环比：本周闭环率 - 上周闭环率
- Top 标签变化：本周高频标签是否与上周一致

### 3.2 周定义

- 本周：当前周报目标周。
- 上周：目标周减 1 个 ISO 周。

### 3.3 同口径原则

环比对比时：

- 保留当前主线筛选
- 保留当前年龄层筛选
- 保留当前标签筛选
- 不强依赖当前周次筛选（避免只筛本周导致上周数据被排除）

### 3.4 无数据处理

若上周在同口径下无数据：

- 环比显示“暂无同口径对比数据”
- 对比值显示 `-`

## 4. 预览区字段对照

预览弹窗支持“领导版 vs 教研版”字段对照，并可切换“只看变化字段”。

变化字段包括：

- 高频风险标签（领导版展示）
- 关键闭环条数（领导版展示）
- 问题明细条数（教研版展示）

## 5. 导出一致性

以下出口使用同一份周报构建逻辑：

- 一键复制周报
- 导出周报 TXT
- 周报预览正文

因此模板切换或口径调整后，三者会同步生效。

## 6. 建议使用策略

- 日常执行同步：优先教研版（便于逐条跟进）。
- 例会/汇报：优先领导版（摘要清晰，节省阅读时间）。
- 月度复盘：建议领导版结论 + 教研版附件。
