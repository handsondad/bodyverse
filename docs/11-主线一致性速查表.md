# 11 主线一致性速查表

## 使用场景
用于课前 3-5 分钟快速检查当前讲解是否保持同口径，避免“误区纠正、cue 结论、正式结论”三处分叉。

## 快速使用步骤

1. 先确定本轮讲解的部位、主线、年龄层。
2. 按下方四主线检查项逐条打勾。
3. 任一项不通过时，先改文案再上课或录制。

## 四主线速查项

### A. 分层解剖
- [ ] 一句话奥秘强调“结构协同”，不是单点发力。
- [ ] 误区纠正没有把“外观正常”直接等同于“功能稳定”。
- [ ] cue 的“回到结论”与正式结论都强调“结构约束 + 传力效率 + 反馈修正”。
- [ ] 年龄梯度符合：4-6 可口语复述，13+ 保留系统模型视角。

### B. 场景故事
- [ ] 一句话奥秘强调“流程接力”，不是孤立步骤。
- [ ] 误区纠正明确“前段变化会影响后段”。
- [ ] cue 的“回到结论”与正式结论都强调“级联传递/稳态影响”。
- [ ] 年龄梯度符合：低龄讲接力，高龄讲链路与扰动传播。

### C. 科学原理
- [ ] 一句话奥秘强调“变量 + 机制”，不是只记数字。
- [ ] 误区纠正避免“单次实验直接下结论”。
- [ ] cue 的“回到结论”与正式结论都强调“变量控制 + 证据约束”。
- [ ] 年龄梯度符合：低龄看现象，高龄做建模和证据判断。

### D. 生病就医
- [ ] 一句话奥秘强调“趋势与风险”，不是单次体感。
- [ ] 误区纠正避免“症状变轻 = 完全恢复”。
- [ ] cue 的“回到结论”与正式结论都强调“动态评估与风险分层”。
- [ ] 年龄梯度符合：低龄讲持续观察，高龄讲风险更新策略。

## 三处同口径核对（必查）

每次讲解至少抽查 1 个主线，核对以下三处是否同口径：

1. 误区纠正（wrong/right/conflictHint）
2. cue 的“回到结论”
3. 正式结论（buildReviewConclusion）

通过标准：三处都在回答同一核心判断，不出现“一个说观察趋势、一个说单点定论”的冲突。

## 常见偏航信号

- 出现“只看一次数据就下结论”。
- 出现“看起来正常就等于功能正常”。
- 出现“前后流程彼此独立，不互相影响”。
- 出现“感觉好一点就当作完全恢复”。

## 处理动作

1. 先改误区纠正文案（src/lib/content-adapter.ts）。
2. 再检查 cue 结尾是否自动复用正式结论（src/data/cue.ts）。
3. 最后复核讲义模板风险提示是否同源（src/App.tsx）。
